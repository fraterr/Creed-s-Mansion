Each game gets its own shelf. Patches are distributed as IPS files and never as ROMs: bring your own copy of a game you already own, apply the patch to it, and keep the original file untouched.

Every entry says which release it was built against and which emulators it has been tested on. If a shelf is empty, nothing has been published for that game yet.
